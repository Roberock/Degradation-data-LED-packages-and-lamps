## Data Description

Raw and normalized data from LED testing. The datasets comprise luminous flux depreciation data, chromaticity shift data and more. See the `LEDdata` folder for more details.

A database of anonymized degradation (longitudinal) and reliability data from several light-emitting diode packages and lamps, obtained from accelerated stress tests such as the IES LM-80 standard.

![plot](/Descriptive_Tables_LED_data.png?raw=true)

- The first table contains a summary of the `.csv` data sheets, including table sizes, test durations, number of samples, number of distinct LED technologies, and number of accelerated stress tests.
- The second table indicates the measured response variables, accelerating factors, and other device-specific parameters. It also shows whether raw data (âœ”) is available or only normalized flux (-) measurements are provided.
